# You Are Bot — Bot Detection in Dialogues

**Binary classification of dialogue participants (human vs bot).**

Проект содержит решение задачи детекции ботов в диалогах из Kaggle-соревнования **You Are Bot!**.  
Цель — по тексту диалога предсказать вероятность того, что каждый участник является ботом.

---

## Задача

- Тип: бинарная классификация
- Объект классификации: **участник диалога**
- Выход модели: `P(is_bot = 1)`
- Метрика: **LogLoss**
- Валидация: 5-fold CV по `dialog_id`

## Подходы

Решение состоит из нескольких независимых источников признаков.  
Для каждого источника обучается отдельная модель с помощью K-Fold,
после чего применяется ансамблевое обобщение.

- Простые фичи
- Эмбеддинги диалога
- Perplexity (PPL) с помощью GPT-подобной модели

## 1. Простые фичи (Behavioral / Stylometry)

Извлекаются напрямую из текста сообщений и структуры диалога.

### Примеры признаков
- средняя длина сообщений
- стандартное отклонение длины
- количество сообщений
- доля повторяющихся сообщений
- echo-index (повторы собеседника)
- доля капса
- доля пунктуации (`! ? ?!`)
- количество эмоджи
- повторяющиеся символы (`аааа`, `!!!`)

## 2. Эмбеддинги диалога

Диалог преобразуется в векторное представление, поверх которого обучается классификатор.

### TF-IDF
- word + char n-grams  
- линейные и бустинговые модели  

### Word2Vec
- усреднение эмбеддингов сообщений участника  

### FastText
- устойчивость к опечаткам и неформальному тексту  

### BERT-эмбеддинги
- sentence-level представления сообщений  
- агрегация на уровне участника  

## 3. Perplexity (PPL) с помощью GPT-подобной модели

- causal language model
- вычисление perplexity для сообщений
- агрегация на уровне участника

## 4. Отдельные модели и ансамбль

Для каждого источника данных обучается отдельная модель.

Используемые модели:
- Logistic Regression
- Random Forest
- LightGBM
- CatBoost
- XGBoost

### Ансамбль
- сбор OOF-предсказаний всех моделей
- meta-модель обучается на вероятностях
- оптимизация напрямую под LogLoss

## Результаты

### Cross-Validation (5-fold)

 Подход - LogLoss :

 Простые фичи  ~0.35
 TF-IDF  ~0.32 
 Word2Vec  ~0.4 
 FastText  ~0.44 
 BERT embeddings  ~0.39 
 PPL only  ~0.4–0.50 
 
---

 **Ансамбль**:
- Logloss 0.29
- Accuracy 0.88
- Bot Precision 0.97
- Bot Recall 0.8
- Human Recall 0.97
- Human Precision 0.82
- Human f1 0.89
- Bot f1 0.87

## Ограничения задачи

- Боты в датасете сильно различаются по стилю
- Большинство ботов написаны людьми
- Часть диалогов неразличима даже для человека
- Теоретический максимум качества ограничен природой данных
