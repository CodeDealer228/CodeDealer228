# Journey to Springfield – Мини-проект

## Описание

Этот мини‑проект — решение задачи классификации изображений персонажей мультсериала “Симпсоны” в рамках соревнования Kaggle: [Journey to Springfield](https://www.kaggle.com/competitions/journey-to-springfield1/leaderboard).

**Цель:** определить, какой персонаж изображён на картинке.

## Данные

- **Ссылка на датасет:**  
  [Kaggle: Journey to Springfield](https://www.kaggle.com/competitions/journey-to-springfield1/data)
- **Краткое описание:**  
  Датасет содержит изображения персонажей “Симпсонов”.  
  Данные разделены на train (с указанием класса/персонажа) и test (без разметки для финального тестирования).  
  Размер изображений варьируется, основная часть — портретные фотографии.

## Решение: Шаги

1. **Анализ данных и препроцессинг:**
    - Все изображения приводятся к фиксированному размеру (224×224) и нормализуются.
    - Осуществляется аугментация для train-выборки (случайные обрезки, повороты, флип, цветовые искажения).

2. **Архитектура модели:**
    - Используется предобученная сверточная нейронная сеть DenseNet-121 (transfer learning).
    - Frozen-фичи: “замораживаются” все слои, кроме последнего блока DenseNet и классификационной “головы”.
    - Классификационный слой заменён на два линейных слоя с Dropout.

3. **Обучение:**
    - Оптимизатор Adam (lr=1e-4, weight_decay=2e-3).
    - Функция потерь — Cross Entropy Loss.
    - Обучение модели на GPU, использование валидации для отбора лучшей эпохи.

4. **Метрика:**
    - Качество оценивается по mean F1 score.

5. **Результаты:**
    - Macro F1 score на тестовой выборке: **0.994** (Kaggle).
