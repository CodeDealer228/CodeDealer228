# Semantic Segmentation of Skin Lesions

Проект посвящён задаче **семантической сегментации** изображений кожных поражений: по входному изображению требуется предсказать бинарную маску области поражения.

## Задача
Сегментировать область интереса на медицинских изображениях кожи.  
Задача формулируется как **pixel-wise binary classification** и решается с использованием сверточных нейронных сетей.

## Данные
Используется датасет дерматоскопических изображений с соответствующими бинарными масками.  
Данные разделены на train / validation / test выборки.  
Перед обучением применяется базовая предобработка и нормализация.

## Модели
В проекте обучаются и сравниваются две архитектуры:

- **SegNet** — энкодер-декодер архитектура с апсемплингом по индексам pooling-слоёв.
- **U-Net** — симметричная энкодер-декодер архитектура со skip-connections, сохраняющими пространственную информацию.

Обе модели реализованы на **PyTorch** и обучаются в одинаковом экспериментальном протоколе.

## Функции потерь
Для обучения и сравнения использовались различные лоссы:
- **Binary Cross-Entropy (BCE)**
- **Dice Loss**
- **Focal Loss**

Это позволяет оценить влияние функции потерь на качество сегментации и устойчивость обучения.

## Метрики качества
Основная метрика:
- **IoU (Jaccard Index)** — основная метрика сегментации

Дополнительно анализируются:
- динамика train / validation loss,
- визуальное качество предсказанных масок.

## Результаты
Лучшие результаты достигаются при использовании **U-Net + Jacard Loss**.

Итогове качество:

**SehNet**
- Validation IoU: 0.68 на Dice loss
 
**U-Net**
- **Validation IoU:** ~0.82 на Jacard loss 
- **Validation IoU:** ~0.78 на Dice loss

## Выводы
- U-Net превосходит SegNet за счёт skip-connections, позволяющих лучше восстанавливать границы объектов.
- Dice Loss и Jacard Loss демонстрируют преимущество над BCE в условиях несбалансированных классов.
- Качество сегментации подтверждается как численными метриками, так и визуальными примерами.

Все эксперименты и визуализации представлены в ноутбуке `Semantic_segmentation.ipynb`.
