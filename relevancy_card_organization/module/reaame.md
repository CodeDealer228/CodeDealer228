# Модульный агент на LangGraph
Обладает модулями Main и Fact_Checker

## Main-модуль
- Формирует список фактов, которые должны быть верны для конкретной орагниазации, исходя из запроса
- Пытается подтвердить каждый факт с помощью карточки
- Если не получается подтвердить факт, вызывает Fact_Checker-модуль
- Классифицирует 1 только если все факты верны (пока версия сырая, работает плохо)

## Fact_Checker-модуль
- Не обладает контекстом main-модуля
- Имеет только организацию (название и адрес) и Факт
- Делает веб-запросы через Tavily, пытаясь подтвердить факт
- Если за 3 запроса не удалось подтвердить факт, то возвращает false
- Если какой-то результат веб-запроса подтвердил факт, возвращает true
